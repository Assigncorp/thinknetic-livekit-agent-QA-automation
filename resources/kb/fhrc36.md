## Section 3 — Product Overview

### Machine Description

The Etnyre Computerized Fixed Hopper ChipSpreader (FHRC36) is a hydrostatic, computer-controlled self-propelled aggregate spreader. It is designed for chip seal (surface treatment) road construction. The machine tows a supply truck while driving forward, spreading aggregate at a precisely controlled application rate.

### Key Systems

| System | Description |
| :---- | :---- |
| Drive | Computer-controlled hydrostatic ground drive (2WD or 4WD) |
| Controller | RC-36 (Rexroth computer) |
| Hopper | Fixed hopper with hydraulically controlled gate and spread roll |
| Individual Gates | Air-cylinder operated, controlled via switches on operator console |
| Conveyors | Two (left and right) rear conveyors feed material from the rear truck into the front hopper |
| Augers | Two (left and right) distribute material in the front hopper |
| Engine | Electronic Cummins diesel (Tier III, IV, or V depending on serial) |
| Hydraulic System | Rexroth AA4VG125 main hydrostatic drive pump \+ Rexroth A10VO74 auxiliary pump \+ gear pump for steering/fan |
| Air System | On-board compressor feeds air cylinders for individual gates; 80 PSI main regulator |
| Steering | Hydraulic power steering |
| Brakes | Hydrostatic braking \+ foot pedal service brake \+ automatic parking brake |

## Section 5 — Material Loading and Unloading

### Overview

The FHRC36 loads aggregate via two rear conveyors that run from the supply truck's dump body down into the front fixed hopper. The conveyors can run in Manual-On, Automatic, or Off mode. The front hopper has a built-in spread roll and gate assembly.

### Rear Conveyor Gate (Flow) Settings

Before operating, ensure the rear hopper flow gates (Ref 6 on the General Identification diagram) are set to deliver as much material as possible into the conveyor without spillage.

### Conveyor Operating Modes

| Control Position | Mode | Behavior |
| :---- | :---- | :---- |
| Selector Switch — Bottom | Manual ON | Conveyor runs continuously |
| Selector Switch — Middle | AUTO | Conveyor runs until ultrasonic sensor detects material; shuts off when hopper is full; restarts when material is low |
| Selector Switch — Top | OFF | Conveyor off |
| Front Control Box Pushbutton (held) | Momentary ON | Overrides selector; conveyor runs while button is held |

### Material Loading Procedure

1. Connect the supply truck to the chipspreader hitch.  
2. Position the rear hopper flow gates to allow aggregate to fall onto the conveyor belts.  
3. Set the Left and Right Conveyor Selectors to AUTO or Manual ON as needed.  
4. Use the conveyor hood positions to control material distribution to the front hopper. A 1½-inch gap is a good starting point for 3/8–1/2-inch chips.  
5. Verify material is evenly distributed across the full width of the front hopper before beginning to spread.  
6. The conveyors should run approximately 80% of the time with the hopper spreading full width at maximum job speed.

### Valve Position Table

| Valve / Switch | Loading (Filling Hopper) | Spreading | Road Travel (Empty) | Towing |
| :---- | :---- | :---- | :---- | :---- |
| Park/Drive Switch | PARK | DRIVE | DRIVE (travel) | PARK |
| Gate/Spread Roll Thumb Switch | OFF | ON (when at spreading speed) | OFF | OFF |
| Gate Override | OFF | OFF (use only to clear jams) | OFF | OFF |
| Conveyor Selector | AUTO or ON | AUTO or ON | OFF | OFF |
| Individual Gate Master Switch | ON | ON | OFF | OFF |
| Individual Gate Selectors | ON (all desired gates) | ON (all desired) | OFF | OFF |
| Hydraulic Suction Gate Valve | OPEN (counterclockwise) | OPEN | OPEN | OPEN |
| Traction Control | OFF | OFF (unless wheel slip) | OFF | OFF |
| Traction Boost | OFF | ON (if loaded, attached to truck) | OFF | OFF |
| Throttle Run/Idle | RUN (high idle) | RUN | RUN | IDLE |

### Unloading / Cleanout

- To clear a jam in the gates: momentarily press and hold the **Gate Override** switch (Ref 23). The gate will fully open above the set point to allow the obstruction to pass. Release to return to the set position.  
- **WARNING:** Never put hands between the gate and spread roll or gate and rear of hopper. The gate can move at any time.  
- To empty the hopper before storage: run conveyors OFF, open gates via Gate Override while moving slowly until hopper is empty.

## Section 6 — System Startup

### Pre-Start Checklist

Before starting the engine, perform the following inspection:

1. **Tires:** Check condition and inflation — front 55–60 PSI, rear 60–65 PSI. Never exceed the maximum inflation pressure on the tire's sidewall.  
2. **Fluid Levels:** Check hydraulic oil level (sight glass on reservoir), engine oil, engine coolant.  
3. **Fuel Level:** Check fuel gauge/tank.  
4. **Grease:** Grease all fittings per the Lubrication Chart (see Section 13).  
5. **Hydraulic Suction Gate Valve:** Verify it is fully OPEN (turned counterclockwise). Starting the engine with this valve closed will cause pump cavitation and damage.  
6. **Hose Connections:** Verify spread roll hoses are connected to the hopper drive motor hoses. Wipe connectors clean before connecting.  
7. **Guards and Shields:** Confirm all shields, covers, and guards are in place.  
8. **Area Clearance:** Make certain everyone is clear of the machine.  
9. **Hopper:** If the optional front hopper segregation screen is installed, raise it before roading between job sites.  
10. **Control Stick:** Place joystick in neutral position.  
11. **Park/Drive Switch:** Confirm it is in PARK.  
12. **Loose Bolts / Leaks:** Check for fluid leaks and loose fasteners.  
13. **Engine Manual:** Refer to the engine operator's manual for complete engine service requirements.

>   
> **CAUTION:** Failure to place Park/Drive switch in PARK position when shutting down will discharge batteries. Auxiliary computer power is routed through the Park/Drive switch.

### Startup Sequence (Normal Operation)

**Step 1 — Set Throttle:** Place the Throttle Run/Idle switch (Ref 32\) in the **IDLE** position.

**Step 2 — Set Mode:** Confirm Park/Drive switch (Ref 2\) is in **PARK**.

**Step 3 — Confirm Joystick Neutral:** Verify the Speed/Direction Control Handle (Ref 9\) is in neutral.

**Step 4 — Turn Key ON:** Rotate the Power/Ignition Switch (Ref 1\) from OFF to ON. All electrical systems and controls power up.

> **NOTE:** The computer will load. The main operator screen displays application rate set point, aggregate size, and speed set point.

**Step 5 — Verify Display:** Main operator screen shows, for example:

   20.0        3/8       400

  lbs/yd2      Chip      fpm

**Step 6 — Start Engine:** Rotate the ignition key to the START position and release when the engine fires. The engine will not start if the Park/Drive switch is in DRIVE.

> **WARNING:** If the joystick is not in neutral at startup, the chipspreader will not move until the joystick is returned to neutral.

**Step 7 — Engine Warm-Up:** Allow the engine to idle briefly. Switch Throttle to **RUN** (high idle) before performing any work. The hydrostatic system is designed to run at high idle.

**Step 8 — Check Alarms:** Scroll through the operator screens to verify normal readings:

- Screen 3: Engine coolant temp, oil pressure, fuel %  
- Screen 4: Hydraulic oil temp, engine RPM (should be \~2,200 RPM at high idle), battery voltage (13.5–15.0 V)  
- Screen 5: Engine hours, feet chipped

**Step 9 — Engage Drive:** When ready to move:

- Move Park/Drive switch to **DRIVE**.  
- Push joystick forward to move.  
- The parking brake releases automatically when joystick moves out of neutral.

>   
> **CAUTION:** Always place the mode selector switch in PARK when the chipspreader is stopped to avoid accidental movement.  
>   
> **WARNING:** Selecting PARK while the chipspreader is moving results in an emergency stop.  
>   
> **WARNING:** Turning the ignition switch to OFF while moving results in a violent stop (all functions except power steering and rear brakes are electrically controlled).

### Hydrostatic System Startup (After Hydraulic Work)

If any hydraulic circuit was opened (filters replaced, hose disconnected, pump removed), follow the full Hydrostatic System Startup procedure in Appendix D:

1. Jack machine up — all four wheels off ground.  
2. Disconnect 50-pin connector at engine (so engine cannot start, only crank).  
3. Disconnect pump stroker at pump.  
4. Install 600 PSI gauge in port "G" on drive pump.  
5. Confirm suction gate valve is OPEN.  
6. Turn ignition ON, throttle to IDLE. Crank engine until charge pressure gauge shows 40–60 PSI. Do NOT crank for more than 30 seconds. Wait 2 minutes before re-cranking.  
7. Reconnect 50-pin connector.  
8. Start engine; let it idle 10 minutes while monitoring charge pressure.  
9. Shut down engine; remove gauges; recheck fluid levels.

## Section 7 — Operating Procedures

### Standard Chip Spreading Work Cycle

**Pre-Spread Setup:**

1. Set aggregate size using the Aggregate Size Switch (Ref 4). Options: Sand, 1/4" Chips, 3/8" Chips, 3/8" Gravel, 5/8" Chips, 1" Chips. Set this BEFORE setting the application rate and calibrating.  
2. Set desired application rate using the Application Rate Switch (Ref 5\) — units are lbs/yd².  
3. Set desired travel speed using the Speed Set Toggle Switch (Ref 3\) — units are FPM.  
4. Place Individual Gate Master Switch (Ref 42\) to ON.  
5. Place all Individual Gate Selector switches (Refs 43/44) to ON for full-width spreading.  
6. Verify conveyors are running (AUTO or ON).  
7. Ensure hopper is loaded with aggregate.

**Spreading Cycle (Auto Speed \+ Auto Gate):**

1. Place control handle in neutral.  
2. Set desired speed using the Speed Toggle Switch (Ref 3).  
3. Turn Gate/Spread Roll switch (Ref 10\) to OFF.  
4. Set desired application rate with Rate Switch (Ref 5), or press the appropriate Memory button.  
5. Push the Speed/Direction handle (Ref 9\) forward smoothly to full forward position to accelerate to the speed set point.  
6. At the **starting line of spreading:** depress the RIGHT side of the Gate/Spread Roll thumb switch (Ref 10\) to turn gates ON.  
7. At the **ending line:** depress the LEFT side of the Gate/Spread Roll thumb switch (Ref 10\) to turn gates OFF.  
8. Return the control handle to neutral to stop.

>   
> **NOTE:** The gates automatically close when chipspreader speed drops below 30 FPM, even if the switch is left ON. If left ON, they will immediately begin to open when forward or reverse speed exceeds 30 FPM.

**Speed Adjustments During Spreading:**

- Use the Speed Toggle Switch to change speed while moving. The chipspreader will smoothly transition to the new set point.  
- Pulling the control handle toward neutral slows the machine without changing the speed set point.  
- The application rate (lbs/yd²) is maintained automatically as long as the chipspreader is within the gate opening limits for the aggregate selected.

**Reversing:**

- Full reverse \= 100% of preset speed in reverse, up to 1,300 FPM.  
- After reversing, press the appropriate Memory button to restore the chipping speed set point.

**Shoulder Work / Partial Width:**

- Turn off individual gate selector switches (Refs 43/44) to disable 6-inch increments on the outer 2 feet and 1-foot sections inward.  
- Adjust individual conveyor speeds to match reduced output rate.

**Clearing Gate Jams:**

- Press and hold Gate Override (Ref 23\) — gate fully opens to release obstruction.  
- Release override — gate returns to set position.  
- **WARNING:** Never put hands between gate and spread roll.

**Hitch Operations:**

- To **detach from truck:** While moving forward, depress Hitch Release (Ref 17 or Ref 50 at front box). Momentarily pull joystick rearward slightly to create slack in hitch. Then push joystick forward while holding the hitch release. Once truck separates, release the button.  
- To **attach to truck:** Press hitch release to open hitch (if not already open). Back into truck. Hitch automatically closes and locks on contact.

**Moving the Seat (Optional):**

- Hold seat shift switch (Ref 16\) right or left to position for operation. Do not travel with seat unlatched.

### Conveyor Management

- Conveyor hoods should position material approximately 1½ inches forward for 3/8–1/2-inch chips; adjust further forward for larger stone.  
- Conveyors should run \~80% of the time with the hopper at maximum width at maximum speed.  
- If spreading clean, dry aggregate, the front hopper agitator can be disengaged by removing the agitator disconnect bolt to reduce wear.  
- For sand or small aggregate: install the optional second agitator to prevent bridging.

### Towing Instructions

If the machine must be towed (e.g., engine failure):

1. Install a chain or strap around the front hydrostatic motor and parking brake assembly. Secure to the front engine crossmember.  
2. Remove four 16mm bolts securing the parking brake to the front axle. Pull the parking brake and motor assembly away from the front axle to disengage the spline.  
3. On 4WD: secure rear motor to frame crossmember and remove in same manner.  
4. Tow only to a loading area — not recommended for long distances.  
5. When returning to service: verify axle differential housings are filled with SAE 90 API GL-5 gear lube.

>   
> **IMPORTANT:** Do not tow the chipspreader before reading the towing instructions. Improper towing will damage hydraulic motors and brakes.

## Section 9 — Calibration

### Why Calibrate

The computer maintains application rate set point by controlling gate opening based on machine speed. If the actual material on the ground differs significantly from the set point, calibration adjusts a density factor for the selected aggregate type.

### When to Calibrate

- When switching to a new aggregate type or source.  
- When actual spread rate on the ground differs from the display set point.  
- After gate transducer replacement.  
- After computer replacement.  
- When accuracy better than ±2.0 lbs/yd² is required.

### Material Calibration Procedure (Hopper)

**Before starting:** Verify spread roll is turning at 100 RPM.

1. Select the aggregate to be calibrated on the display (e.g., "3/8 Chips").  
2. Set the application rate set point to the desired value (e.g., 20.0 lbs/yd²).  
3. Set speed set point to approximately 300 FPM.  
4. Lay the supplied canvas on a flat surface with enough room for the chipspreader to get up to speed before reaching the canvas.  
5. With control handle pushed fully forward to full forward position (ensuring constant speed), maneuver toward the canvas.  
6. Actuate the gate thumb switch approximately 10 feet before the material will hit the canvas.  
7. Deactivate the gate thumb switch once the canvas is covered.  
8. Weigh the material and canvas together with the provided scale.  
9. Empty the canvas and weigh the canvas alone.  
10. Subtract: **Net material weight \= (canvas \+ material) − canvas weight \= lbs/yd²**  
11. Repeat this process a **minimum of 3 times** and average the results.  
12. Compare average measured weight to the application rate set point on the display.

**Accessing Calibration Screens:**

- Press CAL switch UP or DOWN to access calibration screens.  
- The program is universal. For a fixed hopper, scroll past the RIGHT CAL screen to reach the LEFT CAL screen:  
  - RIGHT CAL screen (scroll past)  
  - LEFT CAL screen (use this one for FHRC36)

**Making the Calibration Adjustment:**

- Example: Set point \= 20.0 lbs/yd². Canvas weighed 23.5 lbs → 3.5 lbs heavy.  
- On LEFT CAL screen, press and hold the CAL switch DOWN until the lbs/yd² reads **−3.5**.  
- Press the **SAVE** button. The screen resets to zero. The output is now reduced by 3.5 lbs.  
- To exit calibration screens: press SCROLL UP twice to return to main screen.

**Fine-Tuning While Spreading:**

- If material appears lighter than desired while chipping: press CAL, scroll to LEFT CAL screen, toggle CAL UP to add 1 or 2 lbs, press SAVE. Change takes effect immediately.

**Calibration is permanent** — saved in non-volatile memory when machine is powered down.

### Conveyor Speed Calibration

From the main operator screen, press CAL switch UP or DOWN:

- Left Conv screen shows: press CAL UP (+5%) or DOWN (−5%) to adjust left conveyor speed.  
- Press SCROLL DOWN to go to Right Conv screen; adjust similarly.  
- Press SCROLL UP to return to Left Conv screen.  
- Press SCROLL UP again to see actual speed of both conveyors.  
- Normal range: 10% (slowest) to 99% (fastest). Typical use: \~75–85%.

### Auger Speed Calibration

Same process as conveyor speed, accessed after the conveyor screens by pressing SCROLL DOWN.

- Left Auger and Right Auger screens adjust independently.  
- Normal range: 10%–99%. Typical use: \~75%.

### Joystick Calibration (Setup Screens)

Access: Hold CAL switch up or down while turning the ignition key ON.

1. Scroll to SETUP: JOYSTICK screen. Verify 0.0% at neutral.  
2. Press CAL switch to start calibration sequence. (Warning: completing the full sequence is required once started or existing calibration is lost.)  
3. Screen shows NEUTRAL (\~2.4V) — press CAL to save neutral.  
4. Screen shows FORWARD (\~4.4V) — push stick full forward, press CAL.  
5. Screen shows REVERSE (\~0.7V) — pull stick full reverse, press CAL.  
6. Screen returns to JOYSTICK Actual 0.0%.  
7. Press SCROLL to advance to next screen.

### Gate Transducer Calibration (Setup Screens)

1. Access setup screens (hold CAL and turn key ON).  
2. Scroll to SETUP: LEFT NULL. Gate must be fully closed (1/16" gap between each gate and spreadroll). Value should be 0.00". If not, use CAL switch to set to 0.00. SCROLL to next screen.  
3. SETUP: LEFT SCALE — hold gate override pushbutton. Display should show 4.00". If not: verify gate is fully open, then press CAL switch while holding override. Release override — display should return to 0.00".  
4. Scroll to SAVE AND EXIT — press SAVE button.

**Gate Transducer Voltage Ranges (solid state transducer, wiring: A=Red, B=Blue, C=Black):**

- Gate closed: Blue wire \= 0.5–1.5 VDC (ideal: 1.0 VDC)  
- Gate fully open: Blue wire \= closed voltage \+ \~3.0 VDC (e.g., 1.0V closed → 4.0V open, not exceeding 4.0V or supply voltage of 5.0V)  
- Red wire: 5.0 VDC (supply, not adjustable)  
- Black wire: ground

## Section 10 — Troubleshooting — Machine Systems

### Q: Starter does not crank / machine won't turn over

**Step 1 — Check Park/Drive Switch Position:** The Park/Drive switch must be in PARK to start. If it is in DRIVE, the starter circuit is interrupted. Move switch to PARK and try again.

**Step 2 — Check Emergency Stop Button:** If the Emergency Stop button was pressed, the engine will not crank. Locate the Emergency Stop switch (Ref 40), twist the knob clockwise to reset it.

**Step 3 — Check Circuit Breakers:** Check all circuit breakers on the main panel. Confirm that the Horn circuit breaker is not tripped (it supplies power to the front control box and input switches). Reset any tripped breaker by pressing it.

**Step 4 — Check for Failed Relay or Disconnected Wire:** If the above steps do not resolve the issue, a relay may have failed or a wire may be disconnected. This requires inspection of the relay panel.

**Step 5 — Escalate:** If the problem persists, call Etnyre Parts/Service at 888-586-1899.

---

### Q: Starter cranks but the engine will not start

**Step 1 — Check Display for "ENGINE CAN" Message:** If the display shows ENGINE CAN, there is no CAN bus communication between the computer and engine. Proceed to Step 2\.

**Step 2 — Check Tier 4 Monitor (if equipped):** Is the Tier 4 monitor receiving engine data from the Cummins ECM? If NO → proceed to Step 3\. If YES → proceed to Step 4\.

**Step 3 — Check ECM Fuses:** Check fuses for the Cummins Engine ECM controller. These fuses are located near the power and ground distribution hub at the right rear corner of the Cummins engine (up to 4 fuses depending on engine size). Verify fuse size against the schematic; replace only with same-size fuse. For yellow rubber-insulated glass-fuse holders: pull holder apart and confirm the ring seats over the end of the fuse, not just touching the metal body. Inspect and clean all connections.

**Step 4 — Check E-stop Switch / Fuel Solenoid:** Check the Emergency Stop switch and its connections. Also inspect the fuel solenoid/pump on the Cummins engine for possible issues.

**Step 5 — Escalate:** If the engine still will not start, call Etnyre Parts/Service at 888-586-1899 or your local Cummins dealer.

---

### Q: Machine does not move / will not respond to joystick

**Step 1 — Check Start Latch:** The computer locks the machine from moving on startup. Place Park/Drive switch in PARK and joystick to neutral. Move Park/Drive switch to DRIVE. The machine should now respond to the joystick.

**Step 2 — Check Speed Set Point:** If the speed set point is too low (e.g., 0 or very low FPM), the machine will not move at a perceptible rate. Push the SPEED toggle switch UP or press a memory button to raise the set point. The new set point is displayed while changing.

**Step 3 — Test Brake Pressure Switch:** Turn the machine off. Unplug the electrical connector on the brake pressure switch. Start the machine and attempt to move. **Warning: with this connector unplugged, the service brake alone will not stop the machine.** If the machine moves after unplugging the switch, the brake pressure switch is faulty — replace it.

**Step 4 — Joystick Failure:** Enter service screens (hold SCROLL switch up or down while turning key ON). Scroll to SERVICE: Joystick. The status should show \~0.00 Volts at neutral. If the joystick voltage is out of range, see Joystick Fault section below.

**Step 5 — Pump Failure:**

- If machine moves forward but a "PUMP REV SOL FAILURE" appears when trying reverse: there is an electrical disconnect between computer and pump (or pump and ground) for the reverse solenoid.  
- If machine moves reverse but a "PUMP FWD SOL FAILURE" appears when trying forward: same issue for forward solenoid.  
- Find and repair the loose or broken electrical connection.

**Step 6 — Failed Charge Pump:** Install a 1,000 PSI gauge in port "G" on the drive pump. With engine at low idle, pressure should be \~400 PSI. If it reads near 0 PSI, the charge pump has failed.

**Step 7 — Escalate:** Call Etnyre at 888-586-1899.

---

### Q: Machine speed is limited to 200 FPM and won't go faster

**Step 1 — Check Traction Control Switch:** The traction control switch (Ref 31\) limits speed to 200 FPM when engaged. Check whether the switch was left ON from a previous use. Turn it OFF. The machine speed set point should now be adjustable above 200 FPM.

**Step 2 — Check for Pin Short / Connector Issue:** The traction control input and the right spreadroll switch input are adjacent pins in the computer connector. A stray wire strand can create a false traction control signal.

- Turn off the right spreadroll switch. If speed can now be set above 200 FPM, the issue is inside the connector.  
- Remove the computer connectors, then reconnect and test.  
- Remove the input pins for the traction control switch and right spreadroll switch. Inspect wire crimps; remove any loose wire strands. Reinstall pins.

---

### Q: Machine speed is limited to 400 FPM (4WD) or 600 FPM (2WD)

**Step 1 — Check for ENGINE CAN Warning:** Scroll to screen with engine RPM. If engine is running but shows 0 RPM, there is a problem with communication between the engine ECM and the computer. Check the engine communication harness for broken connections or wiring.

**Step 2 — Check Front Motor Connection:** Enter service screens. Scroll to SERVICE: Front Motor. Status should show \~0.40 Amps. If it shows 0.00 Amps, there is a disconnection between the computer and the front drive motor. Find and repair the break.

**Step 3 — Check Rear Motor (4WD):** Repeat the above step for SERVICE: Rear Motor if this is a 4WD unit.

**Step 4 — Speed Sensor Failure:** Check circuit breakers; check the speed sensor connector at the front drive motor; check other connections between the speed sensor and computer.

---

### Q: Emergency — Machine is broken down in the road and cannot move

Use the Emergency Driveline Disengage Procedure (M-218-11R). This is for emergency use only — to move the machine extremely slowly off the road or onto a transport trailer.

**Step 1:** Install two 04MB x 04MJ fittings (Etnyre Part \# 9410200\) — one in each test port of the high-pressure distribution block bolted to the side of the drive pump (remove the 04MB plugs and install new fittings on both sides of the pump).

**Step 2:** Install one 04 x 65-inch hydraulic hose with 04FJX fittings (Etnyre Part \# 3181497\) across between the two fittings. This creates a loop on the drive system, bypassing the pump and relief system.

**Step 3:** Disable or release the park brake unit (mounted in front of the drive motor on the front axle).

**Step 4:** If the engine does NOT run (or the pump cannot supply brake release pressure): use a porta-power modified with a 04 FJX connection to supply approximately **280–400 PSI** to the parking brake unit to release it.

**Step 5:** If the engine RUNS: place controls in Drive mode, push joystick in direction of movement, and steer as needed. Move the machine VERY SLOWLY (crawl speed only) off the road or onto the trailer.

**WARNING:** This procedure is for emergency situations ONLY. Not intended for travel or long-distance movement. Damage can occur if not done correctly.

### Q: Speed sensor failure alarm / ALARM: SPEED SENSOR FAILURE

**Step 1 — Machine Response:** When this fault occurs, the machine comes to a stop. Bring the joystick to neutral, then move it out of neutral to resume at the reduced speed (400 FPM limit). Reset the computer and correct the fault before resuming normal operation.

**Step 2 — Reset Tripped Circuit Breakers:** Check and reset any tripped circuit breakers.

**Step 3 — Check Speed Sensor Connector:** Check the connector at the speed sensor (magnetic pickup) mounted on the front drive motor output shaft. Check for loose sensor and loose wiring.

**Step 4 — Check Voltages at Speed Sensor Connector (connector disconnected):**

- Wire \#1: 12 VDC  
- Wire \#2: Ground  
- Wire \#3: Speed signal — check continuity  
- GN/Y Wire: Direction signal — check continuity

**Step 5 — Check Voltages in Control Box (connector connected):**

- Wire \#1: 12 VDC  
- Wire \#2: Ground  
- Wire \#3: Speed signal — 4–7 VAC while machine is moving  
- GN/Y Wire: Direction signal — 0 VDC forward, 12 VDC reverse

**Step 6 — Check Computer Wiring:**

- Speed signal: RC-36 Plug 2, Pin 2-13  
- Direction signal: RC-36 Plug 1, Pin 1-41

### Q: Uncommanded motion — machine moves wrong direction / UCMD shutdown

**UCMD Direction (machine moves wrong direction and engine shuts down):**

**Step 1:** The speed pickup is showing the opposite direction from the computer command. The direction wire from the speed pickup may be wired incorrectly or have a broken connection.

**Step 2:** Correct or repair the electrical connections at the speed sensor and at RC-36 Plug 1, Pin 1-41.

**UCMD Speed (engine shuts down when slowing to a stop):**

**Step 1 — Check Joystick Calibration:** Enter setup screens and recalibrate the joystick (see Section 9).

**Step 2 — Adjust Joystick Microswitch:** The neutral microswitch on the joystick may be holding the brake off while the computer is commanding a stop. When the computer sees ongoing machine movement while commanding a stop, it shuts the engine. Remove the joystick from the housing and adjust the microswitch away from the notched plate.

---

### Q: Joystick fault / ALARM: JOYSTICK FAILURE

**Causes:**

- Loss of \+5V supply to joystick  
- Loss of ground  
- Center tap voltage out of range (should be 2.5V ± 1.0V)  
- Reverse switch signal: computer must see reverse switch signal within 2 seconds of moving in reverse; must NOT see reverse switch when moving forward.

**Step 1 — Reset Circuit Breakers:** Check and reset all circuit breakers.

**Step 2 — Check Joystick Calibration:** Enter setup screens and recalibrate joystick (see Section 9, Joystick Calibration).

**Step 3 — Check Reverse Switch Wires:** Inspect wiring for the reverse switch signal at the joystick and at RC-36 Plug 1, Pin 1-33.

---

### Q: No conveyor movement / conveyors not running

**Step 1 — Check for Stalled Belt:** If you hear noise from the hydraulic pump, the belt may be stalled. Turn conveyor speed to 100% and cycle the conveyor switch ON and OFF several times to break the belt free. Also center the conveyor belt on the head pulley and tail pulley, and lower the cutoff plate in the rear hopper.

**Step 2 — Check Speed Setting:** If the conveyor speed percentage is set too low, adjust it to a higher percentage. Normal use is approximately 75%.

**Step 3 — Check Start Latch:** Move joystick to neutral, place Park/Drive switch in PARK. The conveyor switch should now function.

**Step 4 — Check AUTO Mode Operation:**

- If conveyor works in ON position but not in AUTO: check whether material is in the hood (auto switch may sense it and keep conveyor off). Verify the auto switch sensing distance is set correctly.  
- If signal from auto switch is not returning to the computer: check electrical connections.  
- Reset the auto switch using the procedure in the Ultrasonic Sensors section.

**Step 5 — Check for Conveyor Solenoid Failure:** Find and repair any loose or broken electrical connection between the computer and the conveyor solenoid (RC-36 Plug 1: Left Conveyor Solenoid \= Pin 1-30, Right Conveyor Solenoid \= Pin 1-31).

---

### Q: No auger movement

**Step 1 — Check for Stalled Auger:** If hydraulic pump noise is heard, the auger may be stalled. Turn auger speed to 100% and cycle the auger switch ON and OFF several times.

**Step 2 — Check Speed Setting:** Normal auger speed is approximately 75%. Increase if set too low.

**Step 3 — Check Start Latch:** Move joystick to neutral, place Park/Drive in PARK.

**Step 4 — Check AUTO Mode:**

- Check for holes in the switch diaphragm.  
- Ensure material is not touching the auto switch.  
- Check electrical connections to the auto switch.

### Q: Water temperature alarm / overheating

**Step 1 — Verify Temperature:** Confirm coolant is actually exceeding 240°F using a laser probe or mechanical temperature gauge (do not rely solely on the display for this check).

**Step 2 — Clean Radiator:** Clean the front of the radiator to restore airflow.

**Step 3 — Check Coolant Level:** Check engine coolant level in the overflow reservoir and radiator.

**Step 4 — Check for Coolant Leaks:** Inspect hoses, fittings, and the radiator for leaks.

**Step 5 — Check Fan Speed:** With water temperature hot and engine at full throttle, unplug the electrical connector at the fan valve. If fan speed does not increase to full speed:

- Hydraulic problem: valve not shifting completely, damaged gear pump, or damaged fan motor.

**Step 6 — Investigate Radiator / Engine:** If overheating persists after the above steps, investigate radiator blockage or internal engine issues.

---

### Q: Fuel sender alarm / low fuel warning

**Step 1 — Check Fuel Level:** Dip the tank or check the gauge. If the tank is not actually low, proceed to Step 2\.

**Step 2 — Check for Metallic Debris:** Look for metallic debris lying on top of the sending unit (inside the tank), which can cause a false ground.

**Step 3 — Check Wiring Connections:** Inspect all wiring from the sender to the computer for loose or frayed connections.

**Step 4 — Disconnect Sender Wire:** Disconnect the wire from the sending unit. If the alarm quits, check the sender resistance values:

- EMPTY: 240 Ohms (acceptable range: 240–260 Ohms)  
- FULL: 33.5 Ohms (acceptable range: 27.5–39.5 Ohms)  
- If alarm persists with sender disconnected, proceed to Step 5\.

**Step 5 — Check Wiring to Computer:** Check wiring between sender and computer.

**Step 6 — Check Computer Connection:** Check connection at RC-36 Plug 2, Pin 2-18 (Fuel Level Sender).

---

### Q: Hydraulic oil gets hot / hydraulic oil temperature alarm

**Step 1 — Check Oil Level:** Verify hydraulic oil is at the correct level in the reservoir sight glass.

**Step 2 — Verify Temperature:** Confirm oil is actually above 180°F using a laser probe or mechanical gauge.

**Step 3 — Check Fan Speed and Airflow:**

- Clean the front of the cooler to allow airflow.  
- With engine at full throttle, unplug the fan valve connector.  
  - If fan speed increases → electrical problem: check temperature switch in hydraulic tank (should close when tank temp \> 140°F) and temperature switch wiring.  
  - If fan speed does not increase → hydraulic problem: valve not shifting, damaged gear pump, or damaged fan motor.

**Step 4 — Check Filter Restriction:** Check the pop-up indicator on the filter head for filter restriction.

**Step 5 — Check Pump Orifice:** If the orifice screen in the load sense line is plugged, the pump will remain at high pressure. Check load sense line orifice (must be 0.040-inch hole).

**Step 6 — Check Auxiliary Pump Standby Pressure:** Verify standby pressure is 400 PSI.

**Step 7 — Check High Pressure of Pump:** Verify main system high pressure settings.

**Step 8 — Check Function Pressures:** Check all individual circuit pressures to verify they are within specification.

**Step 9 — Identify Heat Source:** Check relief valves and hydraulic quick couplings as potential heat sources.

### Q: Display shows "ETNYRE NO COMMUNICATION"

**Step 1:** The signal from the computer is not being received by the display. Check the green and yellow wire connections at the display connector.

**Step 2:** Check the fuse to the computer (in-line 30-amp fuse on the accessory post circuit).

**Step 3:** Check power and ground to the computer.

### Q: No message on display at all

**Step 1:** Check power and ground connections at the display.

### Q: Gates will not operate (hydraulic buss bar)

**Step 1 — Check Gate Arming Switches:** Confirm the Gate Master switch (Ref 42\) is ON and the individual gate selector switches (Refs 43/44) are ON.

**Step 2 — Check Circuit Breakers:** Check all circuit breakers. Confirm power exists on both sides of the circuit breaker assembly.

**Step 3 — Test with Gate Override:** Press the Gate Override button (Ref 23). If the gate operates with override but not with the thumb switch, there is an electrical issue — proceed to Step 6\. If the gate does not operate even with override, there is a hydraulic issue — proceed to Step 5\.

**Step 4 — Monitor Service Screens:** Enter service screens and observe the output gate command screens. Verify the computer is sending the correct signal.

**Step 5 — Check Hydraulic Gate Valve:** Manually override the spool assembly on the hydraulic gate valve to test operation. If it operates with mechanical override but not electrically → go to Step 6/7. If it does not operate with mechanical override → check hydraulic pressures (see Section 9 gate cylinder relief procedure, target 1,500 PSI).

**Step 6 — Check Gate Transducer:** Refer to the Checking Solid State Gate Transducer procedure (Section 11 Troubleshooting).

**Step 7 — Check Gate NULL/SCALE Calibration:** Verify gate null (0.00") and scale (4.00") are correctly set in the computer setup screens (see Section 9).

**Step 8 — Check Joystick Microswitch:** Confirm the joystick center roller micro switch is activating and being recognized.

**Step 9 — Check Power at Gate Switch:** Check for 12V power across the gate switch in the joystick handle.

> **NOTE for RC-36 / Fixed Hopper:** The gate hold feature (GATE OPEN HOLD, GATE SHUT HOLD) should be set to 0.0 inches in setup screens for fixed hoppers. A non-zero value can prevent the gate from operating in park/manual mode.

---

### Q: Gates are unsteady / hunting / fluttering

**Step 1 — Adjust Gate Open/Close Current Values:** Enter setup screens. Adjust the following parameters:

- LEFT OPEN: should be between 0.900 and 1.000 amp  
- LEFT CLOSE: should be between 0.900 and 1.000 amp (typically 0.950)  
- Use the CAL switch to adjust.

**Value too high:** Gates flutter/hunt and cannot find the desired opening.  
**Value too low:** Gates stop before reaching the desired opening — unrepeatable material delivery.  
**Ideal:** Highest value that still allows gates to settle on the desired opening.

---

### Q: Air gates out of adjustment / loud noise when master power is turned on or off

**Step 1 — Identify Problem:** Determine whether the issue is with the air gate cylinders or the hydraulic gate buss arm.

**For Air Gate Problem:**

1. Back off hydraulic gate buss arm adjustment screws between all buss arms and air gates.  
2. Ensure air pressure is applied (forcing gates closed during adjustment). Adjust air gate adjustment screws to achieve a uniform 1/16" gap across the spreadroll.  
3. Check all buss arm bolts for tightness; replace any bent or broken bolts.  
4. Calibrate gate null/scale in computer setup.  
5. With machine running and hydraulic pressure applied, turn gate master power ON, all individual switches ON, and allow air gates to open to the hydraulic buss arm.  
6. Adjust hydraulic buss arm adjustment screws to contact the air gate stops. Do not force past contact — this can change the transducer setting.  
7. Re-verify null (0.00") and scale (4.00").

**For Hydraulic Gate Buss Arm Problem:**

1. Calibrate gate null/scale in computer setup.  
2. Check gate transducer (see below).

### Q: No gradability / machine cannot climb the grade

**Step 1 — Verify Grade:** Calculate grade percentage with combined weight of chipspreader \+ dump truck \+ aggregate at 80,000 lbs max. At 2,200 RPM and 200 FPM speed set point:

- 2WD: max 6–8% grade  
- 4WD with 160cc motors: max 12–18% grade  
- Check motor size (cc) stamped on the tag on top of the drive motor.

**Step 2 — 2WD Machines:** Disconnect the electrical connector on the front drive hydraulic motor servo (secure the wire). Test on grade at 80,000 lbs.

**Step 3 — 4WD Machines:** Disconnect electrical connectors on BOTH front and rear drive motor servos. Test on grade. If disconnecting servos allows the machine to pull the grade, reconnect servos one at a time to identify which motor servo is causing the problem (servo receiving power that is changing the swash plate position).

**Step 4 — If Disconnecting Servos Does Not Help:**

- Check and verify hydrostatic POR (pressure override) hydraulic pressure.  
- Check and verify hydrostatic main hydraulic pressure (FWD).  
- Check and verify hydrostatic main hydraulic pressure (REV).

### Q: Auxiliary hydraulic pressure will not relieve / hydraulic oil stays hot

**Step 1 — Shut off machine.**

**Step 2 — Close and shut off main hydraulic suction valve.**

**Step 3 — Cap case drain at pump.**

**Step 4 — Remove compensator from hydraulic pump(s).**

**Step 5 — Remove load sense compensator cartridge.**

**Step 6 — Locate the 2mm allen-head orifice inside the housing.**

**Step 7 — Remove orifice.**

**Step 8 — Clean orifice** with a strand of primary wire or torch cleaning kit.

**Step 9 — Re-install orifice.**

**Step 10 — Re-install cartridge and compensator.**

**Step 11 — Uncap and reinstall case drain hose.**

**Step 12 — Open suction valve.**

**Step 13 — Install air regulator** to hydraulic tank through vent filter connection. Apply 3–5 PSI to hydraulic system to push out trapped air.

**Step 14 — Start machine and operate all functions** to ensure oil circulation.

**Step 15 — Check and adjust pressures.** Verify pressure relieves after main pressure is achieved.

---

### Q: Hydraulic standby (load sense) pressure is fluctuating

**Cause:** Missing or contaminated orifice, or bad load sense check valves cause excess oil volume in the load sense system.

**Step 1 — Check Orifice in Load Sense Line Fitting:** Check the orifice in the load sense line fitting(s) at the auxiliary pump load sense compensator valve. Orifice should be present (0.040-inch hole), unobstructed, and properly sized.

**Step 2 — Check Compensator Operation:** Verify pressure responds to system demand.

**Step 3 — Isolate Load Sense Lines:** With engine off, remove load sense lines from compensators and cap them. Check and set standby pressure. If proper pressure is achieved and remains steady, one of the load sense circuit's check valves is contaminated.

**Step 4 — Re-attach Load Sense Lines One at a Time:** Identify which manifold block has the contaminated or faulty load sense check valve.

**Step 5 — Clean or Replace Load Sense Check Valves.**

---

### Q: Spread roll speed is fluctuating

**Step 1 — Check Auxiliary Standby Pressure:** Low standby pressure causes insufficient flow to the spread roll. Target standby pressure is 400 PSI. Adjust if needed (see relief valve settings in Section 9).

**Step 2 — Check and Adjust Spread Roll Speed:** The spread roll should be set to 100 RPM. Use the flow control valve (located between the conveyors, on the gate/spreadroll manifold for standard fixed hopper units). Turn clockwise to decrease speed, counterclockwise to increase.

**Step 3 — Inspect Flow Control Cartridge:** Remove and inspect the spread roll flow control cartridge for contamination or debris.

**Step 4 — Monitor Standby Pressure vs. Spread Roll Speed:** Watch if spread roll speed follows standby pressure changes (i.e., when pressure drops, speed drops). If yes, proceed to Step 5\.

**Step 5 — Inspect Load Sense Check Valves:** Remove and inspect the two load sense check valves (located on top of the auger/conveyor/spreadroll manifold) for contamination, worn springs, or pitted seat assemblies.

## Section 11 — Troubleshooting — Output Quality Problems

### Q: Overlap or heavy material in the center when hoppers are fully extended

**Problem:** Material is heavy in the middle; an overlap is present.

**Solution:** The gate cut-off plate needs to be adjusted by sliding it **further into** the hopper (adjust both sides evenly).

---

### Q: Streak or void in the center of the road

**Problem:** Material is leaving a void or streak down the center.

**Step 1:** Adjust the cut-off plate by sliding it **further out** of the hopper (adjust both sides evenly).

**Step 2:** If the cut-off plate cannot be adjusted further out, adjust the hopper in/out cylinder at the rod end of the cylinder (adjust both sides evenly).

---

### Q: Application rate on the ground doesn't match the display set point

**Step 1 — Check Aggregate Selection:** Confirm the correct aggregate type is selected on the display. An incorrect selection (e.g., 5/8" selected when actually spreading 3/8") will cause significant rate error.

**Step 2 — Run Calibration:** Perform the material calibration procedure (see Section 9). Do at least 3 test runs and average the results before making a calibration adjustment.

**Step 3 — Check Gate Opening Setting:** In setup screens, verify SETUP: GATE OPENING is set to 4.00" (not 5.00" unless this is a big chipper).

**Step 4 — Verify Spread Roll Speed:** Confirm the spread roll is running at 100 RPM before calibrating.

---

### Q: Uneven material distribution across the spread width

**Step 1 — Adjust Conveyor Speeds:** Independently vary the left and right conveyor speeds using the CAL switch in the conveyor speed screen. The goal is to deliver material evenly across the hopper width.

**Step 2 — Position Conveyor Hoods:** Adjust the conveyor hood positions to control material distribution. For 3/8–1/2" chips, start with approximately 1.5-inch gap. Move the hood forward for larger aggregate.

**Step 3 — Check Individual Gate Selectors:** Verify all desired individual gate selectors are ON. If some gates are off, the spread will be uneven.

**Step 4 — Check Air Gate Adjustment:** Check that all air gates have a uniform 1/16" clearance against the spread roll (see Air Gates Out of Adjustment, Section 10).

---

### Q: Application rate is correct but spread appears inconsistent (streaks)

**Step 1 — Check Spread Roll Speed:** If the spread roll speed fluctuates, the material delivery is inconsistent. Verify 100 RPM and address any spread roll fluctuation issues (see Section 10, Spread Roll Speed Fluctuating).

**Step 2 — Check Gate Current Settings:** If gate current is too high, gates will flutter and not find a stable position. Reduce LEFT OPEN and LEFT CLOSE values toward 0.900 amps.

**Step 3 — Check Aggregate Condition:** Wet, dirty, or unusually sized aggregate will not flow uniformly. The aggregate type may need to be changed or the material allowed to dry.

## Section 12 — Troubleshooting — Application-Specific Problems

### Q: Machine is being used for shoulder work — how do I limit spread width?

**Solution:** Use the Individual Gate Selector switches (Refs 43/44). Each switch controls a section of the gate:

- Outer gates: 6-inch increments (the outermost 2 feet on each side)  
- Inner sections: 1-foot increments

Turn off the gate switches for sections where you do NOT want material. Also reduce the conveyor speed on the side that is turned off to avoid overfilling the active portion of the hopper.

---

### Q: Machine is being used on steep downgrades — special precautions?

**WARNINGS:**

- The Chipspreader should always pull the truck, even when the truck assists on upgrades. Never allow the truck to push the chipspreader.  
- On steep downgrades, the truck should assist in braking. Establish clear communication with the truck driver before beginning (radio, hand signals, horns).  
- The parking brake meets SAE J1472 — it may not hold on grades steeper than 15%.  
- The larger the truck or steeper the grade, the longer the stopping distance.  
- Traveling with material in either hopper increases required braking force and stopping distance. Road the machine empty whenever possible.

**Action:** Reduce speed set point for downgrade work; allow extra stopping distance; maintain clear driver communication protocol.

---

### Q: Machine needs to operate at very slow speeds (under 100 FPM) — what settings are needed?

**Solution:** The front (and rear for 4WD) motor threshold current may need to be increased. Enter setup screens, scroll to SETUP: Front Motor. Factory setting is 0.400 amps. While operating at 300 FPM, increase threshold current until a speed change is felt, then back it down until there is no speed change. This is the threshold for very slow speed operation.

---

### Q: Machine was just reassembled after hydraulic work — what must I do before driving?

**Solution:** Follow the full Hydrostatic System Startup procedure (see Section 6). Do NOT drive the machine without purging the hydraulic system of air — this can cause cavitation damage to pumps and motors.

### Wear Plate Adjustments

**Spread Roll Wear Plate (Figure 13):**

1. Turn spread roll and conveyors OFF.  
2. Loosen all spread roll wear plate hold-down bolts.  
3. Adjust wear plate until 1/16" nominal clearance exists between the wear plate and the spread roll across the entire hopper width.  
4. Retighten all hold-down bolts.

**Hopper Gate Wear Plate (Figure 14):**

1. Turn spread roll and conveyors OFF.  
2. Loosen wear plate hold-down bolts.  
3. Extend the plate 1/32" past the gate edge along the entire gate width.  
4. Tighten hold-down bolts.  
5. As wear occurs, repeat adjustment.

**Conveyor Belt Adjustment (Figures 16 & 17):**

- If belt moves toward one side: tighten the tail pulley adjustment bolt on that side until belt runs centered.  
- If tail pulley adjustment alone cannot center the belt, adjust the head pulley bearing:  
  - For right conveyor: loosen four head pulley bearing bolts and adjusting bolt jam nuts. **Run conveyor during adjustment.** If belt runs right → tighten adjusting screws. If belt runs left → loosen adjusting screws. Re-tighten jam nuts and bearing bolts.  
  - For left conveyor: same procedure but directions are reversed (right \= loosen; left \= tighten).  
- Belt should be tight enough to prevent head pulley slippage under full load at governed speed, but not over-tightened (shortens belt and bearing life).  
- Tighten both sides equally.

## Section 15 — Winterizing / Storage

### Before Storage — Complete Procedure

1. **Clean the Machine:** Remove all aggregate, road tar, and debris from all surfaces including the hopper, conveyors, gates, and spread roll area.  
     
2. **Run Engine to Operating Temperature:** Before shutdown, run the engine at operating temperature to fully circulate fluids.  
     
3. **Check Hydraulic Fluid:** Verify hydraulic oil level is at the correct level in the sight glass. Top up with ISO VG 46 hydraulic oil if needed.  
     
4. **Drain / Check Axle Differentials:** If it is the annual service interval, drain and refill differential housings and planetary wheel ends with SAE 90 API GL-5 gear lube.  
     
5. **Grease All Fittings:** Lubricate all grease points per the lubrication chart (see Section 13\) to push out old grease and protect against corrosion during storage.  
     
6. **Air System Drain:** Drain condensation from the air reservoir on the air system.  
     
7. **Fuel System:** Fill the fuel tank to prevent condensation inside the tank. If storing for an extended period, use a fuel stabilizer per the engine manufacturer's recommendation.  
     
8. **Engine Fluids:** Check and top up engine coolant with proper antifreeze concentration for the expected storage temperature. Refer to the engine operator's manual.  
     
9. **Battery:** If storing for more than a few weeks, disconnect the battery or connect a trickle/maintenance charger. Confirm batteries are fully charged before storage.  
     
10. **Hydraulic Suction Gate Valve:** Confirm the suction gate valve is in the OPEN position (counterclockwise).  
      
11. **Park/Drive Switch:** Place in PARK to avoid battery drain from the auxiliary computer circuit.  
      
12. **Chock Wheels:** Install wheel chocks and apply parking brake before leaving the machine.  
      
13. **Cover and Lock:** Install the locking control box cover. Park the machine indoors or cover with a weatherproof tarp. Protect the hopper from rain intrusion.  
      
14. **Tire Inspection:** Check tire pressure and inflate to specification (front 55–60 PSI, rear 60–65 PSI) before storage. Tires can lose pressure over winter.  
      
15. **Optional Hopper Segregation Screen:** If installed, raise and secure the screen to prevent weather damage.

### Returning to Service After Storage

1. Perform the complete Pre-Start Checklist (see Section 6).  
2. Check all fluid levels — hydraulic oil, engine oil, coolant, fuel.  
3. Grease all fittings.  
4. Check tire pressures.  
5. Verify suction gate valve is OPEN before cranking.  
6. Start engine and let it idle for 5–10 minutes before applying load.  
7. Check charge pressure (target: 400 PSI at low idle) after startup.  
8. Check all controls and alarms for correct operation before spreading.

### Script 7: Caller Needs to Calibrate the Joystick

**Agent:** You're experiencing unusual machine behavior and want to recalibrate the joystick?

**Caller:** Yes, the machine seems to lurch when I try to slow down.

**Agent:** That could be a joystick calibration issue. Here's how to recalibrate: with the machine fully stopped and in PARK, hold the CAL switch either up or down while turning the ignition key to ON — do not start the engine. Release the CAL switch when the computer beeps three times. You are now in setup screens.

**Caller:** Okay, I'm in setup.

**Agent:** Press the SCROLL switch down to advance through screens until you see SETUP: JOYSTICK and a reading showing 0.0% at neutral. Is the joystick in neutral?

**Caller:** Yes.

**Agent:** Now press the CAL switch once to begin calibration. The screen changes to show the neutral voltage. Press CAL again to save neutral. The screen then shows FORWARD. Push the joystick all the way forward and press CAL. Then the screen shows REVERSE — pull the joystick all the way back and press CAL. The screen returns to showing 0.0% and calibration is complete. Press SCROLL to advance to the next screen, then scroll to SAVE AND EXIT and press SAVE.
